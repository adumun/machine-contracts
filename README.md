# ADÜMÜN Machine Contracts

Canonical repository for versioned machine-readable contracts, schemas, vocabularies, fixtures and local validators used across ADÜMÜN.

## Authority

Human-readable governance remains in the applicable ADÜMÜN canonical standards. This repository encodes approved semantics for machines and does not create new policy by itself.

## Initial scope

- Workflow contracts
- Work Management contracts
- Initiative Lifecycle profiles
- Controlled vocabularies
- Valid/invalid fixtures
- Local validation tooling

## Validation policy

Validation must be reproducible locally. GitHub Actions are not required evidence when account billing or spending constraints prevent hosted execution; equivalent local validation with retained evidence remains mandatory where applicable.
